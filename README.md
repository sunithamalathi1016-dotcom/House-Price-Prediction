## House Price Prediction

## Overview
This project predicts house prices using Machine Learning and the King County House Sales dataset.

## Dataset
- Dataset: kc_house_data.csv
- Source: King County House Sales Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Algorithm
- Linear Regression

## Features Used
- Bedrooms
- Bathrooms
- Square Footage
- Floors
- Waterfront
- View
- Condition
- Grade
- Year Built

## Results
- R² Score: 0.72

## Project Objective
To build a beginner-friendly machine learning model that predicts house prices based on various housing features.

- `house_price_prediction.ipynb`
- `kc_house_data.csv`
